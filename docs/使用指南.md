# FineBI 智能助手 使用指南

这份指南帮你更快得到想要的答案，也帮你了解这个助手擅长回答什么、不擅长回答什么。

## 这个助手能帮你做什么

- **查文档**：FineBI 的用户手册、操作步骤、排错方法——比如"怎么创建数据预警"、"仪表板权限怎么配置"
- **查看板/数据集信息**（仅管理员、分析师角色可用）：查询系统里有哪些仪表板、数据集的字段结构和行数
- **做二次统计分析、生成图表**：基于已有数据做统计计算、生成可视化报表
- **联网查一些公开信息**：当问题超出内部文档范围、需要查最新的公开信息时

## 这个助手目前不擅长做什么

- **跨多个报表的复杂推理**：比如"帮我分析这三个季度的数据为什么会有这个趋势"这类需要综合判断的问题，目前主要能提供数据本身，深度分析建议自己结合业务判断
- **没有在手册里明确写出来的内容**：如果是很新的功能、或者手册没有覆盖到的边缘用法，助手可能会答不上来或者答得不准

## 怎么问，效果会更好

| 场景 | 效果一般的问法 | 更容易得到准确答案的问法 |
|---|---|---|
| 查操作步骤 | "预警怎么弄" | "怎么给普通用户开通创建数据预警的权限" |
| 查数据集信息 | "那个表有多少行" | "XX 数据集的行数和字段结构是什么" |
| 生成图表 | "帮我做个图" | "把 XX 数据集按月份做成柱状图" |

**一个小技巧**：问题里带上具体的功能名称、数据集名称，比笼统地描述"我想要的效果"更容易命中准确答案——这跟搜索引擎有点像，关键词越具体，结果越准。

## 如果回答看起来不对，或者答非所问

助手目前**不会主动反问**你的问题是不是模糊了——如果发现回答跑偏了，最简单有效的方式是：

1. **换一种更具体的问法重新问一次**，尤其是补充上功能名称、数据集名称这类具体信息
2. **点一下回答旁边的 👍/👎**，这个反馈会被记录下来，帮助后续持续改进
3. 如果反复几次都答不上来，直接联系维护者（Jerry），可能是手册里确实还没覆盖这块内容

## 关于权限

不同角色能看到和使用的功能不完全一样：

- **普通用户**：文档检索、二次统计分析、联网查询
- **分析师/管理员**：在普通用户的基础上，额外可以查询仪表板列表、数据集元数据
- **数据集详细结构查询**（字段明细）：目前仅管理员可用，属于相对敏感的元数据操作

如果发现自己应该有权限但看不到某个功能，联系管理员确认账号角色配置。
